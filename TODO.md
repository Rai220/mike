# TODO: Microsoft 365 — почта и файлы в Mike

Обновлено: 2026-09-07. Исходный [архитектурный план](docs/microsoft-365-integration-plan.md), [PRD web MVP](docs/microsoft365-protected-chat-prd.md), [настройка и эксплуатация](docs/microsoft365-setup.md).

## Статус

Текущая реализация работает в основном [Assistant](https://lispenard.nl.tuna.am/assistant): переключатель Microsoft 365 рядом с существующими возможностями чата включает чтение почты и корпоративных файлов самим Mike. Отдельный экран и переход из обычного чата больше не являются пользовательским сценарием; старый URL перенаправляет в Assistant. [Подключение](https://lispenard.nl.tuna.am/settings/connectors) остаётся в настройках. Объединённый чат **развёрнут на RnD**, миграция 03 применена; проверены основной маршрут, сохранение истории и Microsoft 365 ON/OFF. Предыдущие версии с отдельным чатом сохранены в протоколе как история. Серверная модель — `claude-sonnet-4-6`, срок хранения защищённой истории — 7 дней. [Протокол развёртывания](docs/microsoft365-rnd-deployment.md), [текущий PRD](docs/microsoft365-unified-chat-prd.md).

Подтверждённые live результаты: первоначальный localhost OAuth canary прочитал тело одного письма (token/profile/mail HTTP 200; токены не сохранялись). Затем пользователь вошёл через HTTPS callback Mike: сервер возвращает `status: connected`, проверка Microsoft — `mailAccess: true`. Отдельный синтетический запрос к `claude-sonnet-4-6` через существующий прямой провайдер завершился ожидаемым ответом. На предыдущей версии с отдельным чатом на RnD проверена цепочка: список входящих (1 письмо), ответ модели по письму с проверенной цитатой, повторное чтение зашифрованной истории и просмотр оригинала. Проверочный чат удалён. Дополнительно текущий объединённый маршрут проверен на том же chat ID: список 1 письма без чтения тела → чтение письма с проверенной цитатой → OFF без новых list/search/body запросов → reload зашифрованной истории. В `chat_messages` осталось 0 plaintext сообщений; удаление проверочного обычного чата удалило связанный защищённый payload. Refresh/reconnect и чтение корпоративных файлов не подтверждены. На развёрнутой версии Graph Search файлов по запросу `test` вернул HTTP 200 за 776 мс с пустым результатом без поля `hits`; `searchMicrosoft365Sources` успешно вернул `items: []`. Отдельно наблюдались временные 20-секундные Graph timeouts, безопасно возвращаемые пользователю как ошибка; это не ошибка парсера.
